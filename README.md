# TRPG RPG Core · AI GM 견본

예시 턴을 재생하며 AI 게임 마스터가 입력을 받고, 관련 자료를 전달받아 서술하고, 게임 상태 변경을 제안하는 과정을 확인하는 정적 사이트입니다.

1. **예시 행동 보내기**를 누릅니다.
2. **AI 처리 흐름**에서 캐릭터 상태, 탐험보드, 장소 설정, 과거 기억을 살펴봅니다.
3. **AI 서술 보기**를 누르고 HP 변경을 승인하거나 거절합니다.
4. **상태창**과 **전투보드**에서 같은 HP가 표시되는지 확인합니다. **처음부터**로 다시 진행할 수 있습니다.

견본용 캐릭터·시나리오와 미리 작성한 응답을 사용합니다. 로컬에서 보려면 `index.html`을 브라우저로 열면 됩니다. GitHub Pages는 `main` 브랜치의 `/ (root)`를 배포합니다.
