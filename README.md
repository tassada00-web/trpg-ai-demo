# TRPG RPG Core · AI GM 견본

운영 중인 TRPG RPG Core의 스토리, 파티, 상태창 배치와 탐험·전투보드 스타일을 재사용한 공개 견본입니다. 예시 턴을 따라가며 AI 게임 마스터의 입력, 자료 선택, 서술, 제안 반영을 확인할 수 있습니다.

1. 스토리 하단에서 **행동 전송**을 누릅니다.
2. **이번 요청 자료**에서 캐릭터 상태, 탐험보드, 장소 설정, 과거 기억을 살펴봅니다.
3. **AI 서술 보기**를 누르고 HP 변경을 적용하거나 거절합니다.
4. **상태창**과 **전투보드**에서 같은 HP가 표시되는지 확인합니다. **초기화**로 다시 진행할 수 있습니다.

견본용 캐릭터·시나리오와 미리 작성한 응답을 사용합니다. 로컬에서 보려면 `index.html`을 브라우저로 열면 됩니다. GitHub Pages는 `main` 브랜치의 `/ (root)`를 배포합니다.
